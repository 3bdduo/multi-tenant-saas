# Clinic SaaS - Frontend

ده الـ frontend بتاع مشروع إدارة العيادات. المشروع بيخلي عيادات مختلفة تشتغل على نفس النظام، وكل عيادة عندها دكاترة ومرضى وبيانات منفصلة.

## المشروع بيعمل إيه؟

بيوفر واجهة للمريض والدكتور والأدمن، كل واحد بيشوف اللي يخصه بس.
- المريض يحجز مواعيد ويشوف سجلاته الطبية
- الدكتور يتابع مرضاه ومواعيده
- الأدمن يدير الأطباء والعيادات

## الأدوات اللي استخدمتها

- **Next.js 14** — إطار العمل الأساسي
- **React 18** — بناء الواجهات
- **TypeScript** — عشان الكود يبقى organized
- **Tailwind CSS** — للتصميم
- **Framer Motion** — للأنيميشن
- **jwt-decode** — عشان أقرأ بيانات اليوزر من الـ token
- **Cairo & Manrope** — الخطوط اللي بستخدمها
